# Phase 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A rule-based coach: a one-tap nudge line on each exercise card, a coach card on Home with stalls, PRs and the light week, a per-lift history sheet with an e1RM sparkline, and the same estimates and flags in the weekly Markdown file.

**Architecture:** One pure module, `src/coach.ts`, holds every rule (working weight, Epley estimate, load steps, `suggestNext`, stalls, PRs, light-week triggers, the Home rows) over the same `GymData` the export reads, plus a `CoachState` (light weeks and snooze) kept in a new Dexie key-value table `coach` behind `src/coachStore.ts`. `src/history.ts` learns to skip light-week sessions. `src/weekly.ts` grows three additions. The UI is four new components (`NudgeLine`, `HistorySheet` with `Sparkline`, `CoachCard`, `LightWeekSheet`) wired into the existing Workout, Home and Finish screens. Nothing is stored for a suggestion except the `coach` tag on the rows a tap wrote.

**Tech Stack:** Vite 8, React 19, TypeScript, Dexie 4, plain CSS, Vitest 4. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-01-phase3-design.md`

## Global Constraints

- One tap per set stays. The nudge sits between the "Last" line and the first set row and never touches the dock or the ✓.
- Every new control is at least 56 px tall (`var(--tap)`); tag text is at least 11 px.
- The nudge voice is a conditional offer. Exact copy is in the spec's state table and Task 3; no other wording.
- Keys: machines and cables by `equipmentId`, everything else by `exerciseId` (`keyedByEquipment`). Warm-ups never count. Only finished workouts form sessions.
- Missing effort counts as 8. Epley runs to 15 reps; over 10 is rough. `loadMode` `bodyweight_plus`, `timed` and `height_cm` get no estimate; `height_cm` (Box Jump) gets no coaching at all.
- Singapore time everywhere: stored `+08:00` strings compare as strings; dates from `src/week.ts`; `sgIso()` for now.
- Export JSON: `schema` stays `gymlog/1`; set objects gain `coach` only when present; a top-level `coach` object carries `CoachState`.
- Dexie version 3 adds the `coach` table only. No seed changes. No network use. No em or en dashes in any text the app or the file shows.
- Commit after each task on `main`. Never push: every push deploys the live site and Shafi approves each push.
- `npm test`, `npx tsc --noEmit` and `npm run build` green at the end of every task.

## Review Focus

1. A pyramid session (every working set at a different weight): W is the heaviest weight, reps at W is one set, and the rule must still produce a line. Pinned in Task 2.
2. A light week on a lift with one working set: halving must give one set, never zero. Pinned in Task 3.
3. A kettlebell at the smallest size that stalls or drops: there is no size below, so the line is text only, never a 0 kg offer. Pinned in Task 3.
4. A lift first done inside a light week: no earlier session exists, so the "Last" line and ghost rows fall back to the light session instead of showing nothing. Pinned in Task 5.
5. Fewer than three sessions since a reset: no stall, whatever happened before the reset. Pinned in Task 4.

### Task 3: `suggestNext` and the line copy

**Files:**
- Modify: `src/coach.ts`
- Test: `src/coach.test.ts`

**Interfaces:**
- Consumes: Task 2 exports.
- Produces:
  ```ts
  export type Suggestion =
    | { state: 'light'; tag: 'light'; w: number; count: number; sets: number }
    | { state: 'hold' }                                                             // no tap
    | { state: 'drop' | 'reset' | 'up' | 'reps'; tag: CoachTag; w: number; count: number; sets: number }
    | { state: 'text'; kicker: string; text: string }                               // no tap
  export type Stall = { sessions: number; w: number; reps: number }  // computed in Task 4; the type lives here so Task 3 compiles
  export type SuggestInput = {
    ex: Exercise; eq?: Equipment; bells: number[]
    sessions: Session[]          // for the key, oldest first, light sessions already removed
    lightWeekRunning: boolean
    stall: Stall | null          // from Task 4's stallOf; the tests here pass literals
  }
  export function suggestNext(input: SuggestInput): Suggestion | null   // null when sessions is empty or ex.loadMode === 'height_cm'
  export function lineFor(ex: Exercise, s: Suggestion, lastRows: SetRow[]): { kicker: string; text: string }
  ```
  Precedence: light, hold, drop, reset, up, reps. Effort is `ratingOf(last.rows).rpe ?? 8`. `n` = working sets of the last session. Reps target: `Math.max(min + 1, median)` capped at `hi`, where median is the middle count in sorted order, the lower middle when even; timed lifts use `min + 5`. `mid = Math.ceil((lo + hi) / 2)`. Up fires when every count at W is `>= hi` and effort `<= 9`, or every count `>= mid` and effort `<= 7`; at the top with no next load (bell list end or reps-only) it becomes the `text` state. Drop needs each of the last two sessions to have a count at its own W below `lo`; it is skipped for reps-only. Reset needs `stall` and becomes `text` for reps-only or when no load two steps down exists (one step down when only one exists is NOT used: text instead, so the rule never offers a 0). Copy:

  | State | kicker | text |
  |---|---|---|
  | light | `Light week` | `formatTarget` + `, two sets` when the lift halves (kettlebell, per_hand or reps-only; word for 1 to 4: one, two, three, four; else the digit) |
  | hold | `Hold` | `Last one was a 10. Repeat ` + `formatSession(ex, lastRows)` |
  | drop | `Two short` | `Try ` + target |
  | reset | `Stalled ${stall.sessions} sessions` | `Reset to ` + target |
  | up, reps | `Feeling good?` | target |
  | text, kettlebell top | `Top of the range` | `Try a bigger bell` |
  | text, reps-only top | `Top of the range` | `Repeat ${hi}, then add load` (`Repeat 60s` for an unloaded timed lift) |
  | text, reps-only stalled | `Stalled ${n} sessions` | `Repeat ${target}, then add load` |
  | text, loaded lift with no load below | `Stalled ${n} sessions` or `Two short` | `Repeat ` + `formatSession(ex, lastRows)` |

  // Stall (declared in Task 3): reps is the median count at W of the latest session
